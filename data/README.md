# Dataset Information: IBM HR Analytics Employee Attrition & Performance

- **Dataset File**: `WA_Fn-UseC_-HR-Employee-Attrition.csv`
- **Source**: [Kaggle IBM HR Analytics Employee Attrition & Performance](https://www.kaggle.com/datasets/pavansubhasht/ibm-hr-analytics-attrition-dataset)
- **Author/Publisher**: IBM Data Scientists (Pavan Subhash)
- **License**: Open Database License (ODbL) / Public Domain for educational and benchmarking use.
- **Records**: 1,470 employees
- **Attributes**: 35 columns
- **Target Variable**: `Attrition` (Binary: 'Yes' / 'No')

### Downloading Dataset
If you cloned the repository without the dataset, you can download `WA_Fn-UseC_-HR-Employee-Attrition.csv` directly from the Kaggle link above and place it in this `data/` folder.
